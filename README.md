# Tea Cinematic Landing

A cinematic scroll-based landing page built with:
- React
- Vite
- React Three Fiber
- Three.js

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm install
npm run build
npm run preview
```

## Notes

This package is self-contained and uses embedded SVG artwork generated in code so it can run without external image files.
